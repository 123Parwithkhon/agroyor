# Демо-фото техники

Снимки с Wikimedia Commons под свободными лицензиями. Размер уменьшен до 900 px (для медленного интернета).
Используются только в демо-данных (`npm run db:seed -- --demo`). Подпись с автором и лицензией выводится
на странице объявления (`lib/photo-credits.ts`).
